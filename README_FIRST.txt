AbyssScav - Windows Portable Build

1. Extract the entire ZIP to a normal folder.
2. Run AbyssScav.exe.
3. Solo works without network access.
4. LAN: Host Game -> LAN. Other players use Join Game -> LAN.
5. Internet: Host Game -> Internet. If automatic UPnP fails, forward UDP 24857 on the router or use an optional VPN overlay.
6. Do not run directly inside the ZIP archive.

No login, ads, or automatic analytics are required by the v2.1 design.
