# 17. 플레이어 가이드 (AbyssScav v0.1.0-a01)

심해 잠수정 인양 게임. 어두운 심해에서 잠수정을 조종해 계약 목표를 달성하고, 살아서 귀환하는 것이 전부입니다.

---

## 1. 게임 개요

- **목표**: 계약 선택 → 다이브 → 계약 목표 완료 → 출발 지점(추출 존)에서 귀환 → 정산
- **위험 요소 4가지**:
  - **압력**: 깊이 × 바이옴 압력 계수가 선체 압력 등급을 넘으면 균열·침수 발생
  - **소음**: 엔진/드릴/수리 소음이 클수록 크리처가 멀리서도 당신을 탐지
  - **위협도 (Threat 0–100)**: 시간+소음+apex 존재로 상승. 높을수록 크리처가 공격적으로 변함
  - **전력**: 수요가 공급을 넘으면 소나 저하 → 브라운아웃(소나 완전 정지)
- **정산**: 성공 시 크레딧 + 연구 데이터 + 샤드. 실패해도 보험 등급에 따라 확보 화물 일부 보존

---

## 2. 첫 플레이 — 튜토리얼

메인 메뉴에서 **"Tutorial: The First Ping"** 을 선택하세요. 7단계로 구성됩니다:

1. **조타** — W/S/A/D/Space로 잠수정 움직이기
2. **수동 소나** — 조용히 듣기 (핑 없이도 근처 생물이 감지됨)
3. **능동 핑 (F)** — 360° 스캔으로 목표/전리품/크리처 표시
4. **도킹 (J)** — 스테이션에 25m 이내, 2m/s 이하로 접근 후 도킹
5. **인양 (E)** — 전리품 회수
6. **수리 (R)** — 훈련용 균열을 실란트로 용접
7. **추출 (T)** — 출발 지점에서 귀환

도킹/수리/추출은 **필수 단계**라 스킵할 수 없습니다. 나머지는 스킵 가능하며, 진행 상황은 저장됩니다.

## 3. 게임 루프 상세

### 3.1 계약 선택 화면
- **Waters (바이옴)**: 물의 깊이/압력/위험 결정
- **Contract**: 바이옴에 맞는 계약 목록
- **Frame**: 잠수정 종류 (Skiff/Mule/Warden)
- **Difficulty**: Casual/Standard/Blackwater
- **Run seed**: 월드 생성 시드 (같은 시드 = 같은 지형)
- **Contract modifiers**: 난이도 변형 (선택)
- **Module loadout**: 카테고리당 1슬롯, 보유 청사진만 장착 가능

### 3.2 다이브 중
1. **핑 (F)** 으로 주변 스캔 — 목표 지점(구조물), 전리품, 크리처가 소나에 표시됨
2. 목표/전리품에 접근 → **인양 (E)** (사거리 15m, 화물 슬롯/무게 확인)
3. 상단 중앙의 **목표 진행도** 확인 — 모든 목표 완료 시 "Extract" 안내
4. 출발 지점(추출 존)으로 복귀 → **추출 (T)**
5. 정산 화면: 크레딧/연구 데이터/샤드 수령

### 3.3 메타 진행
- **연구 화면**: 연구 데이터로 모듈 청사진 구매 (효과 구현된 6종만 구매 가능)
- **코덱스**: 조사한 크리처/물/유물 트레잇 기록
- 다음 다이브에서 구매한 모듈을 장착 → 더 어려운 계약/바이옴 도전

## 5. HUD 읽는 법

- **좌측 상단 (계기판)**: 프레임 / 깊이 / 선체(내구도%) / 압력 마진 / 전력(수요/공급) / 소음 / 위협 / 실란트 / 윈치 상태 / 도킹 상태 / 속도
- **상단 중앙 (목표)**: 계약 목표 진행도 (예: `bank_salvage 350/600`)
- **우측 (소나)**: 핑/수동 감지 결과. 구조물(청록), 전리품, 생물(주황) 표시
- **하단 좌측 (화물)**: 슬롯/무게/확보 크레딧/핑·조사 횟수
- **하단 우측 (버디)**: AI 소나 버디 콜아웃 (거리/접촉/경고)
- **중앙 하단 (경고 배너)**: 위협 고조, 브라운아웃, 선체 위험, 압괴 위험 등

## 6. 핵심 시스템 이해

### 압력과 선체
- 압력 마진 = 선체 압력 등급 − 유효 압력(깊이×바이옴 계수×이벤트)
- 마진 < 0이면 균열(creak) → 침수(flood) 위험. 침수는 펌프가 자동 대응하지만 심하면 수리 필요
- **수리 (R)**: 실란트 1개(심한 침수 2개) 소모. 소음+위협 증가
- **실란트**: 시작 3개. 수리/서비스에 사용 — 아껴 쓰세요

### 소음과 크리처
- 소음 0–100. 엔진/부스트/드릴/수리가 소음 발생
- 크리처 탐지 거리 = 기본 청각 × 소음 비례. 소음 높으면 멀리서 접근
- **정숙 운항 (Z)**: 추력 제한 + 능동 소나 비활성. 위협이 높을 때 사용
- 크리처 상태: Dormant → Investigate → Stalk → Hunt → Attack. 공격은 선체 피해 + 균열 가능

### 위협도 (Threat)
- 시간 +0.15/s, 핑 +6~10, 드릴 +0.8/s, 유물 회수 시 트레잇별 가중치
- 위협 60+ → 핑에 가짜 접촉(ghost) 발생, 70+ → 경고 배너
- 위협이 높으면 크리처가 공격 모드로 전환

### 전력
- 수요(추진+생명유지+침수 펌프+드릴) > 공급이면 셰드 레벨 상승
- 레벨 1: 소나 성능 저하 / 레벨 2: 브라운아웃 (핑 불가)
- 부스트/드릴은 전력 대량 소모 — 전력 여유 확인 후 사용

### 도킹과 드릴
- **도킹 (J)**: 목표/서비스 스테이션에서 25m 이내, 2m/s 이하
- **드릴 (H)**: 도킹 상태에서 8초 홀드. 시설 코어는 **드릴로만** 회수 가능
- 드릴 중 이탈하면 취소 (보상 없음)

### 비상 윈치 (X)
- 1회용. 마지막 안전 지점(선체 50%+, 균열 2 미만, 위협 70 미만)으로 복귀
- 도킹 중에는 사용 불가

## 10. 팁 모음

1. **튜토리얼 먼저** — 필수 조작(도킹/수리/추출)을 익히세요.
2. **실란트는 자원** — 수리와 서비스(비콘/코어)에 쓰입니다. 함부로 쓰지 마세요.
3. **위협 70+면 정숙 운항 (Z)** — 핑을 멈추고 조용히 이동하세요.
4. **핑은 위협을 올립니다** — 필요한 때만. no-ping 보너스 모디파이어도 있습니다.
5. **추출은 목표 완료 후에만 가능** — 목표 미완료 시 추출이 거부됩니다.
6. **실패해도 끝이 아닙니다** — 보험 등급(무료 20% 보존)에 따라 확보 화물 일부가 정산됩니다.
7. **연구 데이터를 모아 청사진을 사세요** — 효과 있는 6종부터.
8. **드릴은 도킹 상태에서만** — 8초 홀드, 이탈하면 취소됩니다.
9. **화물 무게 확인** — RescuePod 같은 무거운 목표는 Mule이 편합니다.
10. **코덱스 채우기** — 생물 조사(V)와 유물 인양(E)이 기록됩니다.

## 11. 현재 빌드의 한계

- **멀티플레이 UI 없음** — 네트워킹 레이어는 구현됐지만 로비 화면이 없어 현재 빌드는 솔로 전용입니다.
- **유료 보험 비활성** — 무료 보험(20% 보존)만 선택 가능.
- **접근성 기능 미구현** — 색맹 팔레트/고대비 HUD/키 리매핑은 아직 없습니다.
- **모듈 18개 효과 미구현** — 구매/장착 불가.
